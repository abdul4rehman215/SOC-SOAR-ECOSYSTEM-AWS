# Overview Interview Q&A

## What is the one-line explanation?

A full GenAI security detection-as-code prototype that validates Wazuh content in GitHub, deploys it safely, detects AI-app guardrail abuse at runtime, and closes the SOC loop through Slack, TheHive, audit tables, and dashboards.

## What makes it realistic?

It includes gates, failure paths, audit tables, rollback, real Wazuh rules, runtime telemetry, and case closure sync. It is not just a happy-path demo.

## What would you show first in an interview?

Start with the architecture diagram, then show Flow A CI evidence, Flow B deployment evidence, Flow C Slack/TheHive evidence, and finally the audit/dashboard tables.
