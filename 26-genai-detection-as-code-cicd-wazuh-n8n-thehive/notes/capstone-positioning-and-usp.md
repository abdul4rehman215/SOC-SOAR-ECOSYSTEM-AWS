# Capstone Positioning and USP

This project sits at the intersection of AI security, detection engineering, SOC automation, and incident response.

## Strong positioning statement

A GenAI Detection-as-Code CI/CD prototype that validates Wazuh detection content in GitHub, deploys it through a controlled n8n release workflow, detects AI-app guardrail abuse at runtime, and closes the incident-response loop through Slack, TheHive, and audit dashboards.

## Why it is different

Most AI security demos stop at prompt filtering or a chatbot UI. Most SOC demos stop at Slack alerting. This project connects the full path:

- source-controlled detection content
- CI validation
- deployment governance
- live Wazuh detection
- AI runtime telemetry
- Slack triage
- TheHive case management
- audit and dashboard tables
- closure synchronization

## Portfolio value

This project shows security engineering maturity because it includes both the detection content lifecycle and the runtime response lifecycle.
