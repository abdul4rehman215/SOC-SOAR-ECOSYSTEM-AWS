================================================================================
SECURITY CAPABILITIES ENABLED BY OSQUERY + WAZUH
================================================================================


1. Endpoint Telemetry Monitoring
   Analysts gain visibility into endpoint system state.

2. Threat Hunting
   SQL queries allow investigation of suspicious processes,
   connections, and system activity.

3. Centralized Monitoring
   Endpoint telemetry is centralized in the SIEM.

4. Detection Engineering
   Wazuh rules can trigger alerts from Osquery events.

5. Security Investigations
   Analysts can reconstruct system activity.

6. Compliance Monitoring
   Osquery helps monitor system configurations.

7. Digital Forensics
   Endpoint state can be inspected during investigations.


================================================================================
SOC ECOSYSTEM ROLE OF THIS PROJECT
================================================================================


This project extends the SOC ecosystem by adding:

• Endpoint telemetry monitoring
• SQL-based threat hunting
• Deep system visibility
• Structured telemetry logs
• Centralized SIEM monitoring

It complements existing SOC components such as:

• Wazuh SIEM
• Suricata IDS
• Zeek Network Monitoring
• ModSecurity WAF
• Threat Intelligence Platforms
• Incident Response Platforms (TheHive)
