AI-Powered SOC Alert Triage Automation
Architecture (Plaintext)
=====================================

Project Name:
- AI-Driven SOC Alert Triage Automation (Wazuh + n8n + AI Agent + Email Reporting)

Goal:
- Convert raw Wazuh alerts into analyst-ready triage intelligence in seconds.
- Reduce alert fatigue by forwarding only meaningful (high severity) events.
- Deliver a clean, structured triage report via email with:
  - What happened
  - Risk assessment
  - Recommended actions
  - Clear next step

Key Design Decisions
--------------------

1) Severity Filtering Upstream (Wazuh)
- Two layers of filtering were explored:
  A) Wazuh integration block <level>7</level>
  B) Custom script filter rule.level >= 7
- Final approach keeps filtering upstream to avoid forwarding noise.

2) Full Context for AI (Major Optimization)
- Early results were inconsistent when only partial fields were sent.
- Final workflow passes full raw alert JSON to AI.
- This improved accuracy and reduced “generic” AI outputs.

3) Strict Prompt Engineering (Production Rules)
- No hallucinations policy:
  - Use only JSON data
  - Do not invent missing fields
  - Output must follow strict format
- Ensures stable, analyst-ready output every run.

4) Email as “Analyst Output Interface”
- Many SOC workflows route alerts to dashboards only.
- This project creates a clear “human interface”:
  - clean visual layout
  - severity labels + structure
  - decision support included


Data Flow Summary (One-Liners)
------------------------------

- Wazuh generates alert → custom script forwards JSON → n8n receives webhook
- n8n normalizes fields + retains full context → AI triage generates structured report
- formatter turns triage into professional HTML email → SMTP sends to analyst


Operational Outcome
-------------------

- Manual triage reduced:
  - faster initial investigation (seconds instead of minutes)
  - reduced alert fatigue by severity gating
- Analyst receives:
  - structured intelligence
  - recommended actions
  - next-step directive
- Adds a practical SOAR layer to the SOC ecosystem:
  - Detection → Decision Support → Analyst Notification (fully automated)
