# 🎙️ 🌐 Project Overview Interview Q&A

## Q1. What does this module prove?

It proves master capstone narrative in a practical SOC automation setting.

## Q2. Why is it important?

Because AI-security workflows need reliable controls, evidence, and repeatability. Alerts alone are not enough; the project shows validation, control, triage, audit, and tuning.

The module uses the relevant subset of GitHub, n8n, Wazuh, Slack, TheHive, Python/Bash scripts, JSON schemas, and n8n DataTables.

## Q4. What was tested?

The workflow was tested through a controlled MVP evidence run, with screenshots captured from n8n execution, external systems, and DataTables.

## Q5. What would you improve next?

I would add stronger automated tests, more durable storage, better secrets management, and production-grade error handling.
