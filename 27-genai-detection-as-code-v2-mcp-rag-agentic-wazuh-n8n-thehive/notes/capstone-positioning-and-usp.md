# 🧭 Capstone Positioning and USP

## Positioning

This project is a SOC + AI Security automation capstone. It is not just an n8n workflow or a Wazuh rule pack. It demonstrates an end-to-end engineering lifecycle for GenAI runtime risk.

## Unique selling points

- Connects AI security content CI/CD with runtime SOC triage.
- Handles MCP, RAG/memory, and agentic AI security in one prototype.
- Uses Wazuh as the detection engine, not only application logs.
- Uses TheHive for structured incident response and case templates.
- Includes regression and false-positive analytics for detection maturity.
- Produces portfolio-grade PDFs, GitHub docs, and LinkedIn launch content.
