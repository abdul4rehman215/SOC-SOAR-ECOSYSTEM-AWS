# 🧰 Shared Assets

This folder contains common artifacts reused across flows.

- `config-templates/` safe `.env.ci.example` and configuration placeholders.
- `data-table-exports/` evidence CSV exports from the MVP test run.
- `n8n-final-workflows/` final workflow JSON exports for quick import.
- `source-scripts/` copied helper scripts used by runtime and deployment tests.
- `wazuh/` shared Wazuh rules and decoders.
- `thehive/` TheHive case template material.
