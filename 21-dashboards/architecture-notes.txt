Wazuh Dashboard Engineering & Security Visualization
Parent Project Architecture

============================================================
1. HIGH-LEVEL PURPOSE
============================================================

This parent dashboards project sits on top of the Wazuh monitoring layer
and focuses on turning security telemetry into analyst-friendly visual
visibility for triage, monitoring, ATT&CK mapping, and compliance review.

The project is organized into three dashboard subprojects:

1. SOC Threat Monitoring Dashboard
2. SOC MITRE ATT&CK Coverage Dashboard
3. SOC Compliance & CIS Benchmark Dashboard

Each dashboard is designed to support a different SOC visibility need
while still using the same Wazuh-driven security data foundation.

6. THREAT MONITORING DASHBOARD ROLE
============================================================

SOC Threat Monitoring Dashboard helps answer:

- What alerts are active right now?
- Which alert severities are increasing?
- Which agents are generating the most alerts?
- Which rule groups are most active?
- Are there sudden event spikes that need investigation?
- Where should the analyst begin triage?

Operational value:
- daily SOC visibility
- shift monitoring
- quick triage
- priority identification
- alert trend awareness

============================================================
7. MITRE ATT&CK COVERAGE DASHBOARD ROLE
============================================================

SOC MITRE ATT&CK Coverage Dashboard helps answer:

- Which ATT&CK tactics are being observed?
- Which techniques appear most frequently?
- Which detections are mapped to ATT&CK?
- Where is visibility stronger or weaker?
- How does security activity align with attacker behavior models?

Operational value:
- ATT&CK-aligned monitoring
- detection engineering support
- reporting and communication
- gap awareness
- attacker behavior perspective

============================================================
8. COMPLIANCE & CIS BENCHMARK DASHBOARD ROLE
============================================================

SOC Compliance & CIS Benchmark Dashboard helps answer:

- Which compliance-related findings are visible?
- Which endpoints are failing checks?
- What posture trends are developing?
- Are benchmark-related issues improving or worsening?
- Which systems need hardening attention first?

Operational value:
- posture awareness
- hardening visibility
- benchmark tracking
- compliance-oriented reporting
- security configuration review

11. REUSABILITY MODEL
============================================================

Each dashboard subfolder contains both:

A. Documentation
   - README.md
   - architecture.txt
   - interview_qna.md
   - troubleshooting.md

B. Reusable dashboard object
   - exported dashboard JSON

This supports two goals at the same time:

1. Learning purpose
   Someone can understand how and why the dashboard was created.

2. Practical reuse purpose
   Someone can import the JSON and reproduce the dashboard layout.

14. FINAL ARCHITECTURE SUMMARY
============================================================

This parent dashboards project represents the visualization and
analyst-operations layer of the Wazuh-based SOC ecosystem.

It connects:

raw security telemetry
        ->
Wazuh alerting and indexed data
        ->
dashboard engineering
        ->
analyst visibility
        ->
better triage, monitoring, reporting, and security decision-making

It acts as the umbrella project for three focused dashboard use cases:
threat monitoring, ATT&CK coverage, and compliance/CIS benchmark visibility.
