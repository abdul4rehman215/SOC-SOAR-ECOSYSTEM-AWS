DETECTION PIPELINE SUMMARY

1. Attacker sends malicious payload
2. NGINX receives request
3. ModSecurity inspects traffic
4. OWASP CRS rule matches attack pattern
5. Request blocked (403 Forbidden)
6. Detailed log entry written
7. Wazuh agent collects log
8. Wazuh manager decodes event
9. Alert generated with severity + MITRE
10. SOC investigates attack

============================================================

LAYERED SECURITY MODEL

Layer 7 Protection → ModSecurity (WAF)
Log Engineering → Wazuh Agent
Detection & Correlation → Wazuh Manager
Visibility & Analysis → Wazuh Dashboard
Response Capability → SOC / Active Response
